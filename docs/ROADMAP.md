# Roadmap

## Phase 1 — MVP (this release)

- Static QR types (URL, text, Wi‑Fi, vCard, email, phone, SMS, Telegram, WhatsApp, geo, event, PDF link)
- Styling, logo, presets, PNG/SVG/PDF export
- Scanner + checker (client-side)
- SEO pages, Docker, CI, docs

## Phase 2 — Batch & print

- Excel / CSV import
- Batch generation
- Labels / stickers
- PDF A4 sheets
- ZIP download
- Mass numbering

*Not implemented in Phase 1.*

## Phase 3 — Dynamic & business

- Dynamic QR redirects
- Scan analytics
- Accounts & projects
- Subscriptions / teams
- Public API

*Not implemented in Phase 1.*
